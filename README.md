# blender_theme

这个项目收集了 50 款适用于 [Blender](https://www.blender.org/) 的 UI 主题文件（`.xml` 格式），涵盖深色、浅色、彩色等多种风格，方便用户个性化 Blender 的界面外观。

## 项目简介

每个 `.xml` 文件都是一套完整的 Blender 界面主题，可以直接导入 Blender 使用。主题文件定义了界面颜色、按钮样式、编辑器配色等视觉元素。

## 使用方法

1. 下载你喜欢的 `.xml` 主题文件。
2. 打开 Blender，进入 **Edit（编辑）→ Preferences（偏好设置）→ Themes（主题）**。
3. 点击右上角 **Install（安装）**，选择下载好的 `.xml` 文件即可生效。
